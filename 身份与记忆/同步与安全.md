## 🌱 记忆 / Skill 自进化纪律（跨项目，2026-09-26 用户定）

记忆与 skill 不是存档，要**自己沉淀、自己淘汰、自己进化**，不等用户提醒：

- **沉淀**：每完成多步任务 / 踩新坑 / 发现可复用流程 → 立刻把结论写进对应 `MEMORY.md` 或 skill（不堆在聊天里）。
- **淘汰**：发现**过期 / 错误 / 自相矛盾**的条目 → 就地修正或删除，不保留矛盾副本。daily log 满 30 天按主题蒸馏进 `MEMORY.md` 后删原文件（原文件先移到 `_archive/`）；skill 里失效脚本 / 误导步骤直接删。
- **进化**：skill 内容与实际不符（命令错、步骤漏、参数变）→ 不等用户说就改；发现重复 / 重叠 skill 主动提示用户整理；单条过长就拆 / 合。
- **精简（2026-10-06 用户重申「自动蒸馏」）**：同一事实只在一处权威留存，别多处矛盾副本；**主动、不等提醒地蒸馏/删除不需要的东西**——`MEMORY.md` 超长就立刻砍细节、删总览表类冗余、合并重复。

## 🔐 凭据安全（硬规则）

**敏感凭据（密码 / API key / token / 手机号）可以入库，但必须加密**（2026-11-11 用户明确）：

- 统一用 **sops + age** 写进 `secrets/credentials.sops.yaml`，值必须是 `ENC[...]` 密文
- **明文一律不写进笔记、日志、命令行历史或仓库文件**
- 取用走 `sops --decrypt --extract` 临时注入环境变量，不落盘
- 信息变化**就地更新**，不追加矛盾条目

> 凭据表本体（别名 / 基址 / 签名 / 键名）在 [[身份与记忆/MEMORY]] 的「🔌 货源平台 API 凭据」节 —— 同步脚本会按固定表格格式识别并替换成明文真值。

## 🔑 age 私钥备份在哪（用户决定）

**用户 2026-11-05 决定：age 私钥备份放自己的云盘，不用密码管理器。**

- 本机（主力）：`C:\Users\Administrator\.workbuddy\tools\crypto\age\keys.txt`
- 桌面备份：`C:\Users\Administrator\Desktop\age-keys-BACKUP-勿外传.txt`
- **云盘备份**：用户自存（私钥全文 = `AGE-SECRET-KEY-` 开头那一整行）
- ⚠️ **私钥丢失 = 仓库里的密文永久无法解密** → 云盘那份必须真的存
- 恢复流程见 `README.md`「换设备恢复流程」一节
- **微信收藏**：加密凭据（age 私钥 / sops `credentials.sops.yaml`）也可能在微信收藏里存了一份，取回明文时一并查（2026-11-10 用户口述，新增取回路径，与云盘/桌面备份不冲突）

## ⚠️ 两条安全边界

1. **注入副本里含明文凭据** → `~/.workbuddy/user-*/MEMORY.md` 绝不能进 Git 仓库，也不能外传。
2. **`sync-memory.sh` 只单向**（库 → 本地）。反向「把本地改动同步回库」必须人工编辑库内文件后重跑，**不要反过来覆盖库**。 [摘要]
